## 工具选择

### YouPlot

绘图是数据可视化过程中非常重要的手段，通过编程语言实现数据可视化是一件很容易的事情，很多主流的编程语言都有对应的绘图框架。但是，想要画个图还要配置开发环境、写代码未免太麻烦。YouPlot 则是一款能够让我们在终端下通过命令行的形式实现绘图的一款工具。它不仅支持直接通过 http 接口获取数据输入，还可以兼容 Python 数据处理框架，通过几行代码即可实现数据的可视化。
